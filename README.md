# UniversalVR

UniversalVR is a standalone Meta Quest Android application project.

Version:

UniversalVR APK v0.1.0

## Current Features

- Quest APK project
- UniversalVR menu
- Long Arms setting
- Long Arms range from 0.50x to 3.00x
- BONELAB adapter folder
- Gorilla Tag adapter folder
- Scary Baboon adapter folder
- GitHub Actions APK builder

## Planned Features

- Better UniversalVR menu
- Controller interaction
- Left and right arm controls
- Hand position offsets
- Long Arms presets
- Per-game settings
- Settings saving
- BONELAB integration
- Gorilla Tag integration
- Scary Baboon integration

## Important

The UniversalVR APK is the manager/menu.

Each game requires a compatible game-side adapter before UniversalVR settings can actually change that game's VR behavior.
