# Blud Slop Adapter

UniversalVR adapter target for Blud Slop on Meta Quest.

Planned features:

- UniversalVR Long Arms
- Left arm adjustment
- Right arm adjustment
- Hand position offsets
- Per-game profile support
- Reset controls
- UniversalVR menu connection

Status:

The game is confirmed for Meta Quest, but its actual modding/runtime integration method still needs to be verified before we write the real arm hook.
